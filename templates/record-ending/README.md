# 唱片机结束页 · record-ending

![效果](preview.gif)

1 页结束页，进入后自动播放、一直循环：

- 整页铺一张底图并稍微压暗，左边一个大圆环透出没压暗的原图，像一张唱片，带一圈柔和的阴影，一直匀速转。
- 右上角一支银色唱臂搭在唱片上。
- 右边是毛笔字的结尾标题和几段小字，像电影片尾字幕一样从下往上慢慢滚动，滚完从下面重新开始。

适合演讲、分享会、课程、职业规划大赛的最后一页，配一段感谢语或结束语。

## 让 AI 做

直接对 AI 说，例如：

> 用唱片机结束页做最后一页，标题写「感谢聆听」，下面写两段感谢的话，用这张图。

> 用唱片机结束页，底图换成自带的薰衣草那张。

没说的内容 AI 会帮你补上，做完把 .pptx 和一个网页预览交给你。用 PowerPoint 或 WPS 打开，按 F5 放映，翻到这一页就会自己动起来。

## 自己运行

```bash
pip install -r ../../requirements.txt
python generate.py --title "谢谢聆听" \
  --para "一段旅程走到这里，\n先在此处停一停。" \
  --para "谢谢你认真听完，\n下次再见。" \
  --image 我的图.jpg --out 结束页.pptx --preview 预览.html
```

## 能换什么

下面这些都可以在对话里直接跟 AI 说，AI 会换成对应的参数。

| 参数 | 作用 | 默认值 |
|---|---|---|
| `--image` | 底图。横图最佳（16:9），建议 2K 以上；左半边的内容会透在唱片里，选左边有细节的图。文件夹里另有两张备用底图：`example-2.jpg` 秋日森林、`example-3.jpg` 薰衣草花田 | `example.jpg` 樱花湖岸 |
| `--title` | 结尾标题，毛笔字，4～6 个字最好看 | `谢谢聆听` |
| `--para` | 标题下面的一段小字，**可以传多次**，每段一次；段内用 `\n` 换行，每段两行、每行 12 个字以内，2～3 段就够 | 三段感谢语 |
| `--dim` | 底图压暗程度，0～1 | `0.3` |
| `--spin` | 唱片转一圈的秒数，越小越快 | `7` |
| `--scroll-speed` | 字幕滚动速度倍数，`2` 是两倍快 | `1` |
| `--title-size` / `--body-size` | 标题 / 小字字号（磅） | `72` / `24` |
| `--title-font` / `--body-font` | 标题 / 小字字体文件 | `fonts/MaShanZheng-Regular.ttf` / `fonts/NotoSerifSC-Regular.ttf` |
| `--out` | 输出的 PPT 文件名 | `唱片机结束页.pptx` |
| `--preview` | 同时输出一个网页预览 | 不输出 |

## 搭配建议

| 场景 | 标题 | 小字 |
|---|---|---|
| 职业规划大赛 | 未来可期 | 一路走来的感谢 + 对未来的期许 |
| 课程 / 分享会 | 谢谢聆听 | 本次要点回顾 + 下次预告 |
| 企业年终 | 感谢有你 | 感谢团队 + 新一年的祝福 |

底图选色调统一、左边有画面细节的风景图（水面、树林、花海），唱片转起来最有质感。

## 说明

- 唱片的转动用的是 PowerPoint / WPS 自带的「陀螺旋」动画，字幕滚动用的是「直线」动作路径，都设置成进入这一页就自动开始、一直重复。
- 唱片里透出的是幻灯片背景，所以底图要通过 `--image` 换。
- 所有文字都已转成形状，换一台没装字体的电脑打开也一样；打开后文字不能再直接改，要改就重新运行一次。
- 需要 PowerPoint 2016 及以上、Microsoft 365 或 WPS。网页预览只用来看效果，正式放映以 PPT 为准。
