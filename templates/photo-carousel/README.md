# 多图轮播 · photo-carousel

![效果](preview.gif)

1 页的照片墙展示页：

- 上下两条弧形色带，带白边和投影，中间夹着一排照片。
- 一进入这一页，整排照片就自动从右往左匀速滚动，从第一张一直滚到最后一张（直线路径动画，不用点）。
- 上方色带里是大标题和一行小字条，下方色带里是一段说明文字。

适合年会、年终总结、团建回顾、比赛或活动风采展示这种照片很多、想一页放完的场合。

## 让 AI 做

直接对 AI 说，例如：

> 用多图轮播做一页年会风采，标题「并肩向前 共赴新程」，下面写一句感谢大家的话，用这 8 张照片。

没说的内容 AI 会帮你补上，做完把 .pptx 和一个网页预览交给你。用 PowerPoint 或 WPS 打开，按 F5 放映，照片会自己滚动。

## 自己运行

```bash
pip install -r ../../requirements.txt
python generate.py --images 1.jpg 2.jpg 3.jpg 4.jpg 5.jpg 6.jpg \
  --title "并肩向前　共赴新程" --subtitle "每一次全力以赴，都是团队的高光" \
  --text "感谢每一位并肩作战的伙伴，新的一年继续一起出发" \
  --out 年会风采.pptx --preview 预览.html
```

## 能换什么

下面这些都可以在对话里直接跟 AI 说，AI 会换成对应的参数。

| 参数 | 作用 | 默认值 |
|---|---|---|
| `--images` | 照片，按顺序排成一排。建议 4～10 张横图，3:2 最接近示例效果；竖图也能放，会窄一些 | 文件夹里的 `example1.jpg`～`example6.jpg` |
| `--title` | 上方大标题，两句各 4 个字最好看，中间用全角空格隔开。传 `""` 不显示 | `并肩向前　共赴新程` |
| `--subtitle` | 标题下白色小字条里的一句话，10～16 个字最合适。传 `""` 不显示 | `每一次全力以赴，都是团队的高光` |
| `--text` | 下方说明文字，一句话最好（25 个字以内），最多 2 行，会自动换行。传 `""` 不显示 | 一句年终感谢语 |
| `--color` | 色带颜色（十六进制，不带 #），小字条里的字也用这个颜色 | `C00000`（中国红） |
| `--duration` | 滚完一遍的秒数；填 `0` 按照片数量自动算（照片越多越久） | `20` |
| `--title-font` | 标题字体文件 | `fonts/NotoSerifSC-Bold.ttf` |
| `--subtitle-font` | 小字条字体文件 | `fonts/NotoSansSC-Black.ttf` |
| `--text-font` | 说明文字字体文件 | `fonts/NotoSansSC-Medium.ttf` |
| `--out` | 输出的 PPT 文件名 | `多图轮播.pptx` |
| `--preview` | 同时输出一个网页预览 | 不输出 |

## 搭配建议

| 场景 | 标题 | 色带颜色 |
|---|---|---|
| 年会、年终总结 | 并肩向前　共赴新程 | `C00000` 中国红 |
| 职业规划大赛（实践经历） | 知行合一　步履不停 | `1F4E79` 深蓝 |
| 励志、运动会、团建 | 追光而行　无畏向前 | `E36C09` 活力橙 |

照片里人物别太靠上下边，上下两条色带的弧形会盖住一点照片的上下沿。

## 说明

- 所有文字都已转成形状，换一台没装这些字体的电脑打开，效果也一样；但打开后文字不能再直接改，要改就重新运行一次。
- 照片滚动用的是「直线路径」动画，PowerPoint 2010 及以上、Microsoft 365、WPS 都能播放。
- 网页预览只用来看效果，正式放映以 PPT 为准。
