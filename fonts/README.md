# 字体

这里的字体全部使用 SIL Open Font License 1.1（OFL）授权，可以免费商用、随项目一起分发。每款字体的授权全文在 `licenses/` 里。

| 文件 | 字体 | 适合用在 |
|---|---|---|
| Anton-Regular.ttf | Anton | 英文镂空大字（窄高、有冲击力） |
| BebasNeue-Regular.ttf | Bebas Neue | 英文镂空大字（细一点、更干净） |
| BigShouldersDisplay-Black.ttf | Big Shoulders Display Black | 英文镂空大字（粗黑、偏海报感） |
| ArchivoBlack-Regular.ttf | Archivo Black | 数字、宽字母大字（例如年份 2026） |
| NotoSansSC-Black.ttf | 思源黑体 Black | 中文镂空大字 |
| MaShanZheng-Regular.ttf | 马善政毛笔楷书 | 中文标题（书法感） |
| NotoSerifSC-Bold.ttf | 思源宋体 Bold | 副标题 |
| NotoSansSC-Medium.ttf | 思源黑体 Medium | 署名、小字 |
| Montserrat-Regular.ttf / Montserrat-Bold.ttf | Montserrat | 英文标题、正文（几何感，圆环连招默认） |
| Poppins-Regular.ttf / Poppins-Bold.ttf | Poppins | 英文标题、正文（圆润干净，旋转转盘默认） |

想用自己的字体，把字体文件路径传给模板的 `--xxx-font` 参数即可。注意：系统自带字体和付费会员里的字体大多只能自己用，不要放进这个文件夹再分发。
